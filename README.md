# Twitch Auto Bonus

**Twitch Auto Bonus** — минималистичное расширение для Chrome, которое автоматически нажимает кнопку "Получить бонус" на Twitch. Мгновенная реакция на появление кнопки, возможность включить или отключить автокликер с помощью слайдера.

## ⚡ Особенности

- Автокликер на зелёную кнопку бонуса на Twitch  
- Мгновенная реакция через MutationObserver  
- Включение/выключение через слайдер  
- Минималистичный и лёгкий  

## 🛠 Установка

1. Скачайте или клонируйте репозиторий.  
2. Перейдите в Chrome: `chrome://extensions/`  
3. Включите **Режим разработчика** (Developer Mode)  
4. Нажмите **"Загрузить распакованное" (Load unpacked)**  
5. Выберите папку с расширением (`twitch-auto-bonus`)  

После этого на панели Chrome появится иконка расширения с слайдером включения/выключения.

## ⚙ Использование

1. Откройте Twitch и зайдите на стрим, где есть зелёная кнопка "Получить бонус".  
2. Убедитесь, что слайдер включён.  
3. Автокликер будет нажимать кнопку мгновенно при её появлении.  
4. Для отключения просто выключите слайдер — скрипт перестанет работать.
